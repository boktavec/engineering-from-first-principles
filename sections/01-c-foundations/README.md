# Section 01 — C, Problem Solving & Computer Science Foundations

**Self-paced section** · Six ordered learning sessions · One integrating mini-project · One mastery assessment

Work through sessions at your own pace and advance when you can demonstrate understanding. The complexity increases gradually, while the problem domains deliberately vary.

## Outcomes

- Describe preprocessing, compilation and linking; build a C program from the terminal.
- Use C types, expressions, control flow and functions safely enough for the assigned problems.
- Explain fixed-size arrays, memory layout, bounds and the basics of pointers.
- Reason about value passing vs modifying data through pointers.
- Implement array traversal, search and single-pass state-tracking algorithms.
- Analyze elementary time and **auxiliary-space** complexity.
- Solve and explain an original C mini-project, including tests and debugging evidence.

## Suggested working area

Store your own solutions under `exercises/session-01/`, `exercises/session-02/`, etc. Use short filenames and update notes whenever your reasoning changes. The capstone has its own `project/deep-sea-monitor/src/` and `tests/` directories.

## What to avoid in this section

- Don't tackle `malloc`, `realloc` or linked-list ownership yet; those come next.
- Don't ask AI to fill in the answer before you attempt the problem.
- Don't assume sanitizer success is proof of correctness.
- Don't skip conceptual understanding just because a solution passes the provided examples.

## Gate to Section 02

Complete the core problems, build/test/explain the capstone, answer the closed-notes questions, and solve a fresh transfer challenge independently. Read [MASTERY.md](MASTERY.md) for how to make that decision.
