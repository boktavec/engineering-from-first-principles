## Video and worked demonstrations

- [Harvard CS50x 2026 — Week 1: C](https://cs50.harvard.edu/x/weeks/1/) — the site calls it *Week 1*; this **repo** does not use weekly pacing. Select shorts on types, conditionals, loops, functions as needed.
- [Harvard CS50x 2026 — Week 2: Arrays](https://cs50.harvard.edu/x/weeks/2/) — selectively watch sections on arrays, memory, debugging, and command-line arguments if useful.

## Algorithm and tool references

- [Big-O Cheat Sheet](https://www.bigocheatsheet.com/) — rough time/space comparison; reason about *your code* instead of memorizing a chart.
- [Clang AddressSanitizer](https://clang.llvm.org/docs/AddressSanitizer.html)
- [Clang UndefinedBehaviorSanitizer](https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html)
- [LLDB Tutorial](https://lldb.llvm.org/use/tutorial.html) — debugger reference for stepping, inspecting variables, and breakpoints.

## Suggested reading discipline

For each resource, write: (1) the core mechanism; (2) a prediction you can test; (3) the Python/TypeScript behavior that previously hid this concept; (4) one bug you could catch when reviewing AI-generated C or systems code.
