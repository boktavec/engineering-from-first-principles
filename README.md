# Engineering from First Principles

A self-paced record of my progress through C, data structures and algorithms, computer architecture, systems programming, and Go. This repository is both a learning workspace and a portfolio of the work I can explain and defend.

My approach is to predict, implement, test, explain, and reflect. I advance when I can demonstrate understanding, rather than after a set number of days.

## Start here

1. Read the [getting-started guide](START_HERE.md) and [learning method](docs/LEARNING_METHOD.md).
2. Begin [Section 01: C Foundations](sections/01-c-foundations/README.md).
3. Record work and evidence in the [progress tracker](docs/PROGRESS.md).
